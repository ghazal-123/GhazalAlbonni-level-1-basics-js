#  JavaScript Basics (Level 1) - Exercise Solutions

Welcome to my repository for JavaScript Level 1 Basics! This project contains organized, fully implemented, and verified solutions for foundational programming concepts in JavaScript.

---

##  Repository Structure

The repository is structured into three main directories, each covering a specific core programming concept:

1. **01-hello-console**
   * Focuses on outputting data, working with the developer tools console, and setting up the initial execution environment.
2. **02-variables**
   * Practical tasks on variable declaration (let, const, var), scoping, and data assignment.
3. **03-operators-and-types**
   * Solutions for dynamic data types, type checking, and arithmetic, assignment, and logical operators.
